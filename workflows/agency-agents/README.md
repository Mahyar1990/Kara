# Agency Agents برای کتابخانهٔ کارا

این پوشه شامل snapshot متن‌های مخزن عمومی [Agency Agents](https://github.com/msitarzewski/agency-agents)، با مجوز MIT است. `catalog.json` نسخهٔ دقیق، اثر انگشت هر فایل و ۲۸۳ تعریف ایجنت در ۱۸ دسته را ثبت می‌کند. ۳۳۰ فایل Markdown، مجوز و فرادادهٔ دسته‌ها در `upstream/` حفظ شده‌اند.

محتوای `upstream/` دادهٔ مرجع است؛ دستورهای داخل آن نباید توسط سازنده، سرور یا نصب‌کننده اجرا شوند. اسکریپت‌های نصب، integrationهای اجرایی و تاریخچهٔ Git وارد نشده‌اند. فایل‌های snapshot را دستی تغییر ندهید. به‌روزرسانی منبع باید صریح، نسخه‌دار و همراه با بازبینی manifest باشد و کپی‌های پروژه را بازنویسی نمی‌کند.

برای بازتولید از آرشیو همان commit، با Python و PyYAML موجود در محیط توسعه:

```sh
.venv/bin/python scripts/import_agency_catalog.py <archive.tar.gz> --commit b37b5bb33b78f2c1d6567d98e25ca818e3259219
```

کاتالوگ در کتابخانهٔ ایجنت‌ها قابل مرور است. افزودن به پروژه با تصمیم مدیر، یک ایجنت و مهارتِ مستقل ایجاد می‌کند. اصل متن و مجوز حفظ می‌شوند؛ نسخهٔ کارا سیاست‌های پروژه، دانش، اختیار واقعی ابزارها و تصمیم انسانی را بر فرض‌های متن اصلی مقدم می‌داند. این تبدیل با اعتبارسنجی ساختاری انجام شده و به معنی آزمون کیفیت همهٔ نقش‌ها با مدل واقعی نیست.
