# فرایندها

فایل‌های فرایند Dify پس از ساخت، export و بازبینی اینجا ثبت می‌شوند. هنوز فرایند قابل import تولید نشده است.

برای هر فرایند، نام فایل، هدف، نسخهٔ Dify، نقش‌های وابسته، تنظیمات مدل مورد نیاز و نتیجهٔ اجرای نمونه‌ها در راهنمای کنارش ثبت شود. اطلاعات محرمانه و تنظیمات فردی پیش از commit حذف شوند.

فرایند آغازین: ورود دستی درخواست کلاسور، تحلیل، روشن‌سازی یا تصمیم مالک محصول و برنامه‌ریزی بر اساس نسخهٔ تأییدشده.
