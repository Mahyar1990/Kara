# فرایندها

فایل‌های مشترک فرایند Dify با دستورالعمل و کد متناظر اینجا ثبت می‌شوند. تنظیمات مدل هر محیط فقط در نسخهٔ خصوصی اعمال می‌شوند.

برای هر فرایند، نام فایل، هدف، نسخهٔ Dify، نقش‌های وابسته، تنظیمات مدل مورد نیاز و نتیجهٔ اجرای نمونه‌ها در راهنمای کنارش ثبت شود. اطلاعات محرمانه و تنظیمات فردی پیش از commit حذف شوند.

اولین فایل آماده، [تحلیل درخواست کلاسور](klassor-analysis/README.md) است: ورود دستی درخواست، ثبت نسخه، تحلیل فارسی و ارائهٔ پیش‌نویس برای بررسی مالک محصول. ورود فایل و اجرای آن در Dify هنوز تأیید نشده است.

ثبت تصمیم واقعی مالک محصول و برنامه‌ریزی بر اساس نسخهٔ تأییدشده، مراحل بعدی‌اند.
