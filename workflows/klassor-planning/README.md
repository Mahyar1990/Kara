# برنامه‌ریز فنی کلاسور

نسخهٔ ۰٫۱، دستورالعمل ۰٫۴، Dify 1.17.1.

مسیر: تحلیل ← فرم واقعی بررسی ← تطبیق نسخه، تصمیم و منابع ← پیش‌نویس فنی. رد، اصلاح، پایان مهلت، منابع بررسی‌نشده یا تأیید آزمایشی در مسیر اصلی، برنامه‌ریز را متوقف می‌کند. خروجی همیشه توسعه و مرج را غیرفعال نگه می‌دارد.

قالب مشترک هیچ دانش خصوصی یا توکنی ندارد؛ بدون اتصال زمینه اجازهٔ اجرای برنامه‌ریز نمی‌دهد. `make prepare-planning` نسخهٔ خصوصی را از بستهٔ محلی کلاسور می‌سازد. نام مدل، نام ثبت‌شده در Dify است؛ از کلید API در DSL استفاده نمی‌شود.

برای آزمون ساختگی مستقل:

```
python3 scripts/build_klassor_planning.py --harness --model AIFA-Sand
```

این نسخه تحلیل آمادهٔ ساختگی و منابع ساختگی دارد و تنها در همین مسیر اجازهٔ اجرای آزمایشی برنامه‌ریز می‌دهد. تأیید فرم آزمایشی، تأیید واقعی مالک محصول نیست. نتیجهٔ مدل فقط پیش‌نویس است؛ تطبیق ساختار و شناسهٔ منابع جای بررسی صحت محتوا را نمی‌گیرد.

در فرم بررسی، مناسب بودن منابع برای ارسال به مدل جداگانه ثبت می‌شود. انتخاب نام در فرم احراز هویت سازمانی نیست. اتصال SSO و ثبت نتیجهٔ گفت‌وگوی مالک محصول، TL و توسعه‌دهنده هنوز پیاده‌سازی نشده‌اند.
