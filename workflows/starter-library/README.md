# قالب‌های آغازین عمومی

سه قالب مستقل برای تحلیل درخواست، گزارش تیم و پاسخ مبتنی بر اسناد. فایل‌های JSON با DSL نسخهٔ ۰٫۷٫۰ سازگارند و به‌عنوان YAML نیز قابل دریافت هستند. کتابخانهٔ بستر، هنگام ساخت نسخهٔ مستقل، مدل پیش‌فرض و دانش انتخاب‌شدهٔ همان پروژه را جایگزین می‌کند. هیچ کلید، نشانی خصوصی، ابزار یا شناسهٔ واقعی در فایل‌ها وجود ندارد.

تمام خروجی‌ها نیازمند بررسی انسان هستند. قالب اسناد بدون انتخاب دانش آمادهٔ پروژه قابل استفاده نیست. قالب‌ها خودکار منتشر نمی‌شوند. ورودی نمونهٔ هر قالب در catalog.json ساختگی است.
