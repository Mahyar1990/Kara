# راهنمای استفاده از پروژه

در جزئیات پروژه، «راهنمای پروژه» را باز کنید. ابتدا باید وارد فضای همان پروژه شوید.

راهنما کاربرد برنامه‌ها و فرایندها، قالب‌ها، دانش، مهارت‌ها، ایجنت‌ها، کارتابل و اعضا را توضیح می‌دهد و به بخش مربوط پیوند دارد. تنظیم مدل برای نقش‌های مالک و مدیر نمایش داده می‌شود. این صفحه راهنمای استفاده از امکانات است و شمارندهٔ پیشرفت، گام‌های تکمیل‌شده یا گزارش توسعه نمایش نمی‌دهد.

مالک پروژه اعضا را دعوت می‌کند و سطح دسترسی آن‌ها را مشخص می‌کند. اعضای دارای مجوز ساخت برنامه می‌توانند برنامه را تنظیم کنند و نتیجهٔ آن را قبل از انتشار بررسی کنند. این صفحه برنامه‌ای اجرا یا منتشر نمی‌کند و تنظیمات مدل را تغییر نمی‌دهد.

کنترل دسترسی راهنما با عضویت و فضای مستقل پروژه انجام می‌شود. صفحهٔ راهنما شمارش و شواهد اجرای API آمادگی پروژه را دریافت نمی‌کند؛ کنترل دسترسی بخش‌های مقصد همچنان برقرار است.
