# محیط توسعهٔ محلی

## مسیر و نسخه‌ها

این مخزن مستقل از فایل‌های همگام‌شدهٔ پروژهٔ گفتگو است. کد مشترک داخل آن نگهداری می‌شود و Remote بعداً توسط مالک پروژه اضافه خواهد شد.

- Dify: نسخهٔ 1.17.1، با commit دقیق در `infra/dify.lock.json`.
- محیط اجرای این Mac: Docker با Colima، پروفایل جدا به نام `company-agent`.
- تنظیم VM این سیستم: ۴ پردازنده، ۴ GiB حافظه و دیسک مجازی ۳۰ GiB.
- پورت وب: 8080 و دسترسی فقط از همین سیستم.

## راه‌اندازی روی Mac

اگر Docker فعال دارید، از همان محیط استفاده کنید. برای سیستم فاقد محیط Docker:

```sh
brew install colima docker docker-compose
colima start --profile company-agent --cpu 4 --memory 4 --disk 30 --vm-type vz --runtime docker
```

راه‌انداز، Docker Compose نصب‌شده به صورت plugin یا فرمان مستقل را تشخیص می‌دهد. به تغییر فایل تنظیمات سراسری Docker برای یافتن plugin نیاز ندارد.

داخل مخزن:

```sh
make setup
make up
make doctor
```

سپس <http://localhost:8080/install> را باز کنید و حساب مدیر را بسازید. مشخصات مدیر و اتصال مدل در همین رابط تنظیم می‌شوند. برای اتصال مدل شرکت، آدرس و شناسهٔ مدل و قالب واقعی API باید از تیم مدل دریافت شود.

## داده و توقف

تنظیمات خصوصی Dify در `.runtime/dify/docker/.env` و دادهٔ سرویس‌ها در پوشه‌ها و volumeهای محیط محلی نگهداری می‌شوند. `make setup` تنظیمات موجود را حفظ می‌کند و رمزها را در اجرای مجدد عوض نمی‌کند.

```sh
make down
colima stop --profile company-agent
```

این توقف داده‌ها را حفظ می‌کند. برای شروع بعدی ابتدا Colima را راه‌اندازی و سپس `make up` را اجرا کنید.

## بررسی و همکاری

```sh
make check
make status
make doctor
```

`make check` فایل‌های قابل اشتراک را بررسی می‌کند و به مدل یا Docker نیاز ندارد. `make doctor` موتور Docker، محدودبودن پورت‌ها به همین سیستم، صفحهٔ وب و پاسخ API را بررسی می‌کند. موفقیت آن، کیفیت مدل یا فرایند ایجنت‌ها را تأیید نمی‌کند.

پس از دریافت سرور، سورس همین مخزن و نسخهٔ ثابت Dify روی آن راه‌اندازی می‌شوند. تنظیمات دسترسی تیمی سرور جدا از تنظیمات محدود به سیستم محلی تهیه خواهند شد.

## وضعیت اجرای واقعی

نصب ابزارهای لازم انجام شده است. راه‌اندازی ماشین و سرویس‌های Dify در حال انجام است؛ نتیجهٔ نهایی پس از بررسی ثبت می‌شود. حساب مدیر، اتصال مدل شرکت و اجرای فرایند هنوز تکمیل نشده‌اند.
