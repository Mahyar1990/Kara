# محیط توسعهٔ محلی

## مسیر و نسخه‌ها

این مخزن مستقل از فایل‌های همگام‌شدهٔ پروژهٔ گفتگو است. کد مشترک داخل آن نگهداری می‌شود و Remote بعداً توسط مالک پروژه اضافه خواهد شد.

- Dify: نسخهٔ 1.17.1، با commit دقیق در `infra/dify.lock.json`.
- محیط اجرای این Mac: Docker با Colima، پروفایل جدا به نام `company-agent`.
- تنظیم VM این سیستم: ۴ پردازنده، ۴ GiB حافظه و دیسک مجازی ۳۰ GiB؛ برای ساخت رابط، ۴ GiB حافظهٔ swap نیز داخل همین VM آماده شده است.
- پورت وب: 8080 و دسترسی فقط از همین سیستم.

## راه‌اندازی روی Mac

اگر Docker فعال دارید، از همان محیط استفاده کنید. برای سیستم فاقد محیط Docker:

```sh
brew install colima docker docker-compose
colima start --profile company-agent --cpu 4 --memory 4 --disk 30 --vm-type vz --runtime docker
```

راه‌انداز، Docker Compose نصب‌شده به صورت plugin یا فرمان مستقل را تشخیص می‌دهد. به تغییر فایل تنظیمات سراسری Docker برای یافتن plugin نیاز ندارد.

در اجرای نخست، دریافت اجزا و آماده‌شدن API زمان می‌برد. راه‌انداز پس از شروع سرویس‌ها تا پنج دقیقه منتظر پاسخ واقعی API می‌ماند. آماده‌شدن کانتینر با آماده‌شدن برنامه یکسان نیست.

رابط فارسی و راست‌به‌چپ از سورس نسخهٔ ثابت ساخته می‌شود. ساخت اولیه روی این سیستم به حافظهٔ موقت نیاز دارد و ممکن است چندین دقیقه طول بکشد؛ اجرای روزمره از تصویر ساخته‌شده استفاده می‌کند. شرایط ساخت و فعال‌کردن swap پس از شروع مجدد VM در [راهنمای رابط فارسی](persian-interface.md) آمده است.

داخل مخزن:

```sh
make setup
make up
make doctor
```

سپس <http://localhost:8080/install> را باز کنید و حساب مدیر را بسازید. مشخصات مدیر و اتصال مدل در همین رابط تنظیم می‌شوند. برای اتصال مدل شرکت، آدرس و شناسهٔ مدل و قالب واقعی API باید از تیم مدل دریافت شود.

## داده و توقف

تنظیمات خصوصی Dify در `.runtime/dify/docker/.env` و دادهٔ سرویس‌ها در پوشه‌ها و volumeهای محیط محلی نگهداری می‌شوند. `make setup` تنظیمات موجود را حفظ می‌کند و رمزها را در اجرای مجدد عوض نمی‌کند.

تنظیم مشترک Compose، کلید اتصال اجرای کد در API و پردازشگرها را از همان `SANDBOX_API_KEY` خصوصی سرویس sandbox می‌گیرد. این تطابق برای تنظیمات موجود نیز اعمال می‌شود؛ تفاوت کلیدها باعث خطای ۴۰۱ در گره کد می‌شود. خود کلید در فایل مشترک قرار نمی‌گیرد و `make doctor` تطابق آن‌ها را بدون نمایش مقدار بررسی می‌کند.

```sh
make down
colima stop --profile company-agent
```

این توقف داده‌ها را حفظ می‌کند. برای شروع بعدی ابتدا Colima را راه‌اندازی و سپس `make up` را اجرا کنید.

## بررسی و همکاری

```sh
make check
make status
make doctor
```

`make check` فایل‌های قابل اشتراک را بررسی می‌کند و به مدل یا Docker نیاز ندارد. `make doctor` موتور Docker، محدودبودن پورت‌ها به همین سیستم، نسخهٔ سفارشی رابط، زبان و جهت سند HTML و پاسخ API را بررسی می‌کند. موفقیت آن، کیفیت مدل یا فرایند ایجنت‌ها را تأیید نمی‌کند.

پس از دریافت سرور، سورس همین مخزن و نسخهٔ ثابت Dify روی آن راه‌اندازی می‌شوند. تنظیمات دسترسی تیمی سرور جدا از تنظیمات محدود به سیستم محلی تهیه خواهند شد.

## وضعیت اجرای واقعی

در ۷ اکتبر ۲۰۲۶ نصب ابزارها، راه‌اندازی VM، اجرای سرویس‌های Dify و فعال‌سازی رابط فارسی و راست‌به‌چپ تکمیل شد.

- `make up`: موفق؛ انتظار برای پاسخ API نیز تکمیل شد.
- `make doctor`: موفق؛ تصویر سفارشی فعلی فعال است، صفحهٔ نصب HTTP 200 با زبان `fa-IR` و جهت `rtl` ارائه شد و API پاسخ `pong` داد.
- `make check`: موفق؛ نسخهٔ ثابت، نمونه‌ها، دستورالعمل‌ها، لینک‌ها و قواعد Git بررسی شدند.
- در ساخت رابط، ۵۹۴۷ کلید ترجمه و حفظ متغیرهای داخل متن بررسی شد و هر شش آزمون CSS موفق بودند.
- درخواست آزمایشی با زبان انگلیسی و کوکی انگلیسی نیز سند فارسی و راست‌به‌چپ دریافت کرد.
- فونت محلی وزیرمتن با قالب معتبر WOFF2 و مجوز همراه آن، هر دو با HTTP 200 ارائه شدند.
- اجرای مجدد setup، تنظیمات خصوصی و رمزهای موجود را حفظ کرد؛ دسترسی فایل تنظیمات 0600 است.
- پورت‌های منتشرشده به 127.0.0.1 محدودند و سرویس‌ها در حال اجرا هستند.

حساب مدیر توسط مالک پروژه ساخته شد و مدل شرکت در Dify ثبت است. فرایند تحلیل درخواست کلاسور نیز از مرورگر وارد و نسخهٔ ۰٫۴ آن با سه درخواست ساختگی در موتور Dify آزمایش شد. [گزارش اجرا](klassor-analysis-dify-evaluation.md) نتیجه‌ها و محدودیت‌ها را دارد.

مشکل موقت بررسی سیاست امنیتی مرورگر پس از بازکردن دوبارهٔ برنامه در این نوبت مشاهده نشد؛ دسترسی از مسیر معمول برقرار بود و تنظیم امنیتی مک یا مرورگر تغییر داده نشد. اجرای اولیه یک ناهماهنگی کلید sandbox را آشکار کرد که در تنظیم مشترک اصلاح شد؛ بازراه‌اندازی سه سرویس، اعتبارسنجی Compose و doctor موفق بودند.
