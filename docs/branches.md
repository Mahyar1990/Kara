# شاخه‌های بستر و ایجنت‌ها

## مرز تغییرات

| شاخه | محتوای قابل نگهداری |
| --- | --- |
| `master` | راه‌انداز Dify، نسخهٔ ثابت، Compose، رابط فارسی و راست‌به‌چپ، اتصال مدل، بررسی‌های عمومی و راهنمای همکاری |
| `agents` | تمام محتوای بستر مشترک، به‌اضافهٔ قالب‌ها و فرایندها، دستورالعمل نقش‌ها، زمینهٔ فنی، نمونه‌ها، تست‌ها و گزارش‌های ایجنت‌ها |

فایل `AGENTS.md` دستورالعمل همکاری با مخزن است و در هر دو شاخه وجود دارد. پیاده‌سازی ایجنت‌ها در `prompts/`، `workflows/` و `fixtures/`، ابزارهای ساخت و بررسی آن‌ها در `scripts/` و مستندات مرتبط در `docs/`، متعلق به شاخهٔ `agents` هستند. این فایل‌ها در تاریخچهٔ `master` قرار ندارند.

## انتخاب شاخه

برای کار روی بستر:

```sh
git switch master
git switch -c feat/dify-your-topic
make check
```

برای کار روی ایجنت:

```sh
git switch agents
git switch -c feat/agent-your-topic
make check
```

قبل از تغییر شاخه، کار ناتمام را در شاخهٔ مربوط ثبت یا به روشی قابل بازیابی نگهداری کنید. هر کامیت همچنان فقط یک کار مستقل را ثبت می‌کند. فایل تنظیمات شخصی، توکن، پاسخ واقعی مدل و دادهٔ Dify خارج از Git می‌مانند.

مقصد MR تغییرات Dify، `master` و مقصد MR تغییرات ایجنت‌ها، `agents` است. برای دریافت تغییرات جدید بستر، `master` در `agents` ادغام می‌شود؛ پس از اضافه‌شدن Remote، این ادغام نیز با MR و تأیید دستی TL انجام می‌شود. کل شاخهٔ `agents` در `master` ادغام نشود، زیرا ایجنت‌ها دوباره وارد شاخهٔ بستر می‌شوند.

## جداسازی تاریخچهٔ موجود

در ۲۰۲۶-۱۰-۰۹، بخش‌های بستر و ایجنتِ کامیت‌های قبلی جدا شدند و شاخهٔ `main` به `master` تغییر نام داد. کامیت‌های بستر، از جمله فارسی‌سازی و اصلاح اتصال sandbox، روی `master` قرار گرفتند. کامیت‌های ایجنت با حفظ ترتیب، پیام تاریخی و هویت نویسنده، روی همان بستر بازچینی شدند. شناسهٔ کامیت‌های بازچینی‌شده تغییر می‌کند. شاخه‌های موضوعی قبلی نیز به کامیت متناظر در تاریخچهٔ جدید متصل می‌شوند.

نسخهٔ بازیابی Git پیش از جداسازی با `git bundle` تهیه و اعتبارسنجی شد. فایل آن و نگاشت شناسه‌های قدیم به جدید در `.runtime/git-reorganization-2026-10-09/` خصوصی و خارج از Git نگهداری می‌شوند. این بازچینی محلی است؛ مخزن هنوز Remote ندارد.

برنامه‌های واردشده در Dify داخل بانک دادهٔ محیط محلی نگهداری می‌شوند. تغییر شاخهٔ Git، فهرست برنامه‌های استودیو را تغییر نمی‌دهد. جداسازی حاضر مربوط به کد، فایل‌های قابل اشتراک و تاریخچه است؛ محیط و دادهٔ اجرای Dify مستقل از شاخه نگهداری می‌شوند.
